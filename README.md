# design-pattern
Implementation of the 7 core design patterns covered in the course, organized into the three classic families (Creational, Structural, Behavioral) with runnable demos in each module.

| Family | File | Patterns |
| :--- | :--- | :--- |
| Creational | `creational_patterns.py` | Singleton, Factory Method, Builder |
| Structural | `structural_patterns.py` | Adapter, Decorator |
| Behavioral | `behavioral_patterns.py` | Strategy, Template Method |

Run each module independently from the terminal:
```bash
python creational_patterns.py
python structural_patterns.py
python behavioral_patterns.py
